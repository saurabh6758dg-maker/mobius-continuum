\begin{abstract}
Continual on-the-job adaptation in Small Language Models (SLMs) without catastrophic forgetting remains an unsolved bottleneck for edge AI. Deployed neural networks confronted with sequential task adaptation suffer from orthogonal weight interference, low-rank representation lossiness (digit drift), and quadratic latency scaling under in-context retrieval (RAG). In this work, we propose the \textbf{Möbius Continuum}, a Dual-Memory Complementary Learning System (CLS) combining a non-parametric Hippocampal Vault with isolated modular synaptic neurogenesis (rank-$8$ LoRA adapters) dispatched by an attentive linear classifier router ($1.26\text{ ms}$ latency). Evaluated on Qwen 2.5 ($0.5\text{B}$-Instruct) under CPU constraints, our systematic 4-way ablation demonstrates that while LoRA-only ($0.0\%$) and Vault-only ($50.0\%$) fail under strict token budgets, the Möbius Hybrid architecture achieves $100.0\%$ precision on unseen challenge queries, matching full-context RAG while delivering $7\times$ faster latency ($0.85\text{s}$ flat vs $5.95\text{s}$) with bounded $O(1)$ context overhead ($\le 25$ tokens). Across an $N=50$ multi-task benchmark (MMLU and GSM8K), the system yields $+7.33\%$ Backward Transfer with zero catastrophic degradation of foundational capabilities.
\end{abstract}

\section{Introduction}
Modern Large Language Models (LLMs) and edge-deployed Small Language Models (SLMs) remain fundamentally static post-pretraining. Context windows provide transient in-context memory, but linear token accumulation incurs quadratic computational overhead, latency explosions, and context dilution. Conversely, updating parameter weights sequentially triggers catastrophic forgetting and representation degradation.

We introduce the \textbf{Möbius Continuum}, an edge-optimized architecture inspired by Complementary Learning Systems (CLS) theory. The framework decouples exact episodic entity memorization from procedural syntactic execution.

\section{Architecture & Methodology}
The Möbius architecture integrates three core components:
\begin{enumerate}
    \item \textbf{Hippocampal Episodic Vault:} A non-parametric $O(1)$ store mapping concept anchors to verified symbolic and numerical ground-truth entities.
    \item \textbf{Synaptic Neurogenesis (LoRA $r=8$):} Domain-isolated low-rank adapters ($\Delta W = B \cdot A$) trained to convergence on procedural reasoning schemas without interfering with foundational weights.
    \item \textbf{Attentive Linear Router:} A 4-class linear projection head trained over pooled input token embeddings with out-of-domain rejection, operating in $1.26\text{ ms}$.
\end{enumerate}

\section{Empirical Evaluation & Ablation}
All experiments were executed on local consumer CPU hardware without CUDA acceleration to evaluate edge viability.

\subsection{4-Way Systematic Ablation}
As shown in Table~\ref{tab:master}, neither isolated LoRA nor isolated Vault suffices for reliable execution:
\begin{itemize}
    \item \textbf{LoRA Only ($0.0\%$):} Low-rank projections compress inputs into continuous semantic manifolds, inevitably causing discrete token drift on high-entropy passwords, PINs, and formulas.
    \item \textbf{Vault Only ($50.0\%$):} Under tight edge generation limits ($\le 35$ tokens), base models exhibit verbosity, pluralization errors, and token exhaustion prior to stating target mechanisms.
    \item \textbf{Möbius Hybrid ($100.0\%$):} The synaptic adapter acts as a learned conciseness and schema regularizer, extracting ground-truth facts with zero grammatical drift.
\end{itemize}

\subsection{Catastrophic Forgetting & Task Interference}
Evaluating $N=50$ unique problems (35 MMLU across multiple scientific disciplines and 15 GSM8K arithmetic problems) reveals a positive Backward Transfer ($\text{BWT} = +7.33\%$), verifying that foundational knowledge remains completely preserved. In contrast, forcing all tasks into a Single Shared LoRA caused complete representational collapse ($0.0\%$ recall).

\section{Limitations & Future Work}
Our findings are empirically grounded on a $0.5\text{B}$ parameter backbone on consumer CPU hardware. Future scaling will investigate validation across $7\text{B}$ and $70\text{B}$ models, hierarchical router tree topologies, and multi-seed variance distributions across $100+$ concurrent enterprise tasks.

\section{Conclusion}
The Möbius Continuum demonstrates that separating episodic non-parametric grounding from synaptic neurogenesis resolves the stability-plasticity dilemma in edge SLMs, delivering RAG-equivalent precision with invariant $O(1)$ latency and zero catastrophic forgetting.
